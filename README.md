# Homebrew Tap for Ascension

ANSI/ASCII art viewer and text editor for macOS.

## Installation

```bash
brew install --cask vigo/ascension/ascension
```

## Update

```bash
brew upgrade --cask vigo/ascension/ascension
```

## Uninstall

```bash
brew uninstall --cask ascension
```
